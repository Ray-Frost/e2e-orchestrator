# design-docs

This folder stores Architecture Decision Records (ADRs) for major technical choices in this repository.

## What Is an ADR?

An ADR (Architecture Decision Record) is a short document that captures:

- the context and problem,
- the options considered,
- the chosen decision,
- and the consequences/follow-up impacts.

ADRs make decisions explicit and easier to review later, especially when contributors change over time.
